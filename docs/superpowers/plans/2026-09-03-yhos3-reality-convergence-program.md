
All of the following must be true:

- one real request enters through a documented invocation path;

- no hard authority/privacy gate fails;

- no recommendation/plan is counted as ACT;
- no ACT is counted as OUT;
- no OUT is automatically counted as attribution or reusable learning.

## 6. G3｜Zero-Management Proof

### Mother claim

> After the system has learned, does the next comparable health episode require materially less Principal management while preserving sovereignty, safety, and decision quality?

### Burden dimensions

- Principal time spent
- Principal manual actions
- Principal decisions requested
- interruptions / attention switches
- repeated questions the Office should already know
- coordination steps handled by Office vs Principal

### Target behavior

```text
first episode:
research → decide → coordinate → act → settle

later comparable episode:
context match → preload learned default → Office handles routine path
→ Principal interrupted only for material decision / exception / clinical gate
```

G3 is not “zero human involvement.” It is **minimum necessary Principal involvement**.
